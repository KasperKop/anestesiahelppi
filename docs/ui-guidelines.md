# Ulkoasun periaatteet

Ulkoasussa käytetään lämmintä vaaleaa taustaa, valkoisia kortteja ja sinisiä toimintoja. Tavoite on rauhallinen puhelimella luettava näkymä. Värit ovat `src/theme/tokens.ts`-tiedostossa.

| Käyttö                     | Väri      |
| -------------------------- | --------- |
| Tausta                     | `#F7F3EB` |
| Kortti                     | `#FFFFFF` |
| Vaaleansininen pinta       | `#EAF6FC` |
| Toimintoväri               | `#2DAAE1` |
| Pääteksti                  | `#202124` |
| Lisätieto                  | `#6B7280` |
| Kriittisen tiedon korostus | `#D92D20` |

Punainen on varattu painokortin hätälääkeosion kaltaiseen korostukseen. Tavalliset toiminnot ovat sinisiä. Merkitys kerrotaan myös tekstillä.

## Näkymät

- Etusivulla painovalitsin on ylimpänä ja chat sen alapuolella.
- Chatissa otsikko ja lyhyt vastaus ovat pääasia. Hakutiedot, lähteet ja lisenssit avautuvat **Näytä lähteet** -painikkeesta.
- Tallennetut vastaukset käyttävät samaa vastauskorttia kuin chat.
- Omat pinot -näkymään pääsee näkyvästä välilehdestä; eleitä ei tarvita.
- Painokortin tiedot ryhmitellään lyhyisiin osioihin.

## Tekstityyli

Käytä tavallista suomea ja samoja nimiä: **painokortti**, **lähteet**, **tallennettu vastaus** ja **Omat pinot**. Kerro toiminnosta suoraan. Älä kutsu prototyyppiä valmiiksi hoitotyökaluksi tai wikiartikkelia tarkistetuksi hoito-ohjeeksi.

## Saavutettavuus

Painovalitsimella on nimetyt plus- ja miinuspainikkeet liukusäätimen lisäksi. Järjestämistoiminnot ovat painikkeita. Kattava näppäimistö-, ruudunlukija-, kontrasti- ja suuren tekstin tarkistus on vielä avoin [tehtävässä #5](https://github.com/KasperKop/anestesiahelppi/issues/5). Dokumentoitu tavoite ei tarkoita, että koko sovellus olisi saavutettavuustestattu.
