# Käyttöpolut

Nämä polut kuvaavat nykyistä portfoliodemoa. Niissä ei käytetä potilastietoja.

## Painokortin avaaminen

1. Valitse etusivulla 3–30 kg liukusäätimellä tai miinus- ja pluspainikkeilla.
2. Paina **Näytä painokortti**.
3. Tarkastele valitun painon taulukkoarvoja ja palaa takaisin.

Kortit sisältävät myös lääketietoja, mutta sisältö ei ole kliinisesti validoitua. Virheellinen paino ei saa avata jonkin muun painon tietoja.

## Kysymys ja vastauksen tallennus

1. Kirjoita chatille yleinen oppimiskysymys tai valitse esimerkkikysymys.
2. Lue tiivistelmä. **Näytä lähteet** avaa hakusanat, hakujen tilat, katkelmat ja lisenssit.
3. Paina **Tallenna vastaus** -sydäntä.
4. Avaa vasemmanpuoleinen **Omat pinot** -välilehti.

Jos sopivaa tietoa ei löydy, chat kertoo siitä. Palveluvirhe tai käyttöraja näkyy virheilmoituksena. **Esittelytila** käyttää valmiita vastauksia ilman lähdehakua.

## Korttien järjestäminen

1. Luo nimetty pino Omat pinot -näkymässä.
2. Avaa tallennettu kortti ja siirrä se haluamaasi pinoon.
3. Muuta korttien järjestystä painikkeilla.
4. Nimeä pino uudelleen tai poista se tarvittaessa.

Pinon poistaminen jättää kortit Järjestämättömiin. Kortin poistaminen pyytää vahvistuksen. Tallennus on paikallinen eikä päivitä vastausta lähteiden muuttuessa.

Pyyhkäisy ja raahaaminen eivät ole toteutettuja toimintoja. Muistilistan kuittauspolku on vasta jatkoidea.
